About this project

FinPirScope predicts how much, and how quickly, a movie gets pirated, by combining a pirated-movie listing dataset with TMDB movie metadata.

Pipeline

  1. Clean the pirated dataset (downloads/views to numbers, run-time to minutes, dates, rare categories to “Other”).
  2. Merge with TMDB data by cleaned title + release year (left join).
  3. Question 1: top-third vs bottom-third by downloads (middle third dropped). Models: Decision Tree, XGBoost, KNN.
  4. Question 2: uploaded faster vs slower than the median number of days after release (only movies uploaded within a year). Models: Decision Tree, Random Forest, KNN.

Things to keep in mind

  • The two classes are balanced, so random guessing ≈ 50%.
  • Q1 relies a lot on “days online”: older uploads simply had more time to be downloaded.
  • Only a minority of titles matched TMDB, so TMDB fields are optional in the form.
  • This is an academic prediction exercise on a historical dataset, not a tool for finding or accessing pirated content.
